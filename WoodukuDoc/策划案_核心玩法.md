## 1. 产品定位与一句话卖点

- **品类**：类数独 / Queens 变体——在色块棋盘上用逻辑排除，找出全部「解方块」。
- **主题包装**：木纹感色块棋盘 + 猴子解方块 + 香蕉星级评价。
- **品牌 / 核心角色**：Monkeydoku；解方块与角色统一为猴子（不再使用大鹅 / 猫主题包装）。
- **一句话**：在 N×N 色块棋盘上，每色、每行、每列各放一只猴，且猴与猴八邻不相碰，找齐即通关。
- **胜利条件**：玩家正确确认全部 N 个解方块（猴）后，本关成功结束。

## 2. 棋盘与关卡结构



### 2.1 棋盘

- 棋盘必须为正方形，边长 `N`，共 `N×N` 格。
- 坐标约定：行 `r ∈ [0, N)`，列 `c ∈ [0, N)`（实现可改 1-based，文档统一 0-based）。



### 2.2 颜色区域

- 恰好存在 **N 种颜色**。
- 每种颜色对应一块 **四连通**（上下左右）的色块区域，覆盖若干格；全部色块合起来恰好覆盖棋盘且无重叠。
- 每种颜色有且仅有 **1** 个解方块（猴）。



### `2.3 解集合`

- `关卡配置须保证：在三条核心规则下存在 唯一解（唯一一组 N 个解方块位置）。`
- 配置侧校验：解集合满足颜色唯一、行列唯一、八邻不接触；且无第二组合法解。



### 2.4 局内进度展示

- 展示形式：`已找到 / 总数`，总数恒为 `N`（对齐 UIGame，如 `1/6`）。
- 「已找到」= 当前被正确确认为解方块的格子数。

## 3. 核心规则（权威定义）

设解方块集合为 `S`，`|S| = N`。对任意格子 `(r, c)`：

### 3.1 颜色唯一

每种颜色在 `S` 中恰好出现一次。

### 3.2 行列唯一

- 任意两解方块不同行、不同列。  
- 等价：每一行恰好一个解方块，每一列恰好一个解方块。



### 3.3 八邻不接触

任意两个不同解方块 `(r1, c1)`、`(r2, c2)` 须满足：

```
max(|r1 - r2|, |c1 - c2|) ≥ 2
```

即：不可处于彼此的八邻格（上、下、左、右、左上、右上、左下、右下）。

### 3.4 通关

玩家将 `S` 中全部位置正确确认为解方块后 → 通关成功。

### 3.5 合法 / 非法示意（八邻 vs 四邻）

以下仅示意邻接差异（假设其它规则已满足）：

```
合法（对角相隔一格以上或不相邻）：
  猴 . .
  . . .
  . . 猴     → max(|Δr|,|Δc|)=2，合法

非法（斜角接触——四邻规则会误判为合法，八邻必须判非法）：
  猴 .
  . 猴       → max(|Δr|,|Δc|)=1，非法

非法（正交相邻）：
  猴 猴      → 非法
```

**验收要点**：斜角相邻的两只猴必须判为非法；实现时禁止只做四邻检测。

## 4. 玩家操作与格子状态



### 4.1 格子状态机


| 状态     | 含义         | 表现       |
| ------ | ---------- | -------- |
| 未定义    | 尚未判定       | 空白格（仅底色） |
| 排除(X)  | 玩家标记为「不是解」 | 显示 X     |
| 确认解(猴) | 玩家标记为解方块   | 显示猴子图标    |


状态转移（默认手势，见下节）：

```
未定义 --单击--> 排除(X)
排除(X) --单击--> 未定义
未定义 --双击--> 确认解(猴) 或 错误反馈
确认解(猴) --单击或再次双击--> 未定义（撤回，见 4.3）
```

滑动批量打 X 时：路径上「未定义」变为「排除(X)」；已是「排除」或「确认解」的格子在滑动路径上 **不改写**（避免误擦猴）。

### 4.2 手势定义


| 操作    | 行为                   |
| ----- | -------------------- |
| 单击    | 在「未定义 ↔ 排除(X)」间切换    |
| 双击    | 尝试标记为解方块（猴）          |
| 按住后滑动 | 经过的格子批量打 X（仅作用于未定义格） |


双击判定建议：第二次点击与第一次间隔 ≤ 280ms，且落在同一格；超时则按两次单击处理。

### 4.3 错误放置与撤回

- **错误双击**（该格不是解方块）：不进入「确认解」；该格显示 X（进入排除），并计 **1 次错误**；扣 **1 颗血**；可给短震动/闪红反馈。
- **正确双击**：进入「确认解(猴)」；进度 +1；不记错误、不扣血。
- **撤回确认解**：对已是猴的格子单击（或再次双击）→ 回到未定义；进度 -1；不记错误、不扣血。
- **错误双击已排除格**：若玩家对已是 X 的格双击，且该格仍非解：保持 X，仍计 1 次错误并扣 1 颗血（或首版可忽略双击、仅单击切换——推荐 **仍计错误并反馈**，防止乱点试错无代价）。
- 血量规则见 **5.1.1**；扣至 0 → 进入失败界面（本关失败，不结算星级）。



### 4.4 底部工具与手势关系（对齐 UIGame）

底部两个圆形入口：

1. **猴工具（角标：剩余可确认数或剩余未找出数）**
  - 角标数值 = `N - 已正确确认数`（与进度互补）。  
  - **首版默认**：不切换「模式」，猴仍靠 **双击** 放置；该按钮用于聚焦提示「还要找几只」或打开简短规则条。  
  - 若后续做「单击即放猴」模式：进入模式后单击=双击语义，再次点按钮退出；与滑动打 X 互斥（模式中禁用滑动打 X）。
2. **提示（灯泡，角标：剩余提示次数）**
  - 见第 5.3 节。

顶部：返回、关卡号、分数（首版分数可与星级联动或暂显 0）、设置。

## 5. 局内系统



### 5.1 关卡信息（HUD）


| UI 元素 | 内容                                |
| ----- | --------------------------------- |
| 返回    | 退出本关（未通关不强制存星级；可弹确认）              |
| 关卡号   | 「关卡 {id}」                         |
| 分数    | 首版可用「错误越少分越高」占位，或通关后再结算；HUD 可暂显 0 |
| 设置    | 音效/音乐/重开本关等                       |
| 进度    | 猴子图标 + `已找到/N`                     |
| 生命    | **三颗血**（见 5.1.1）；错误一次熄灭一颗           |
| 星级预览  | 三枚香蕉（通关结算点亮；进行中可按当前错误/提示预估灰态）    |
| 规则条   | 三句：一种颜色一只猴 / 同行同列各一只 / 猴子不能接触（八邻） |


### 5.1.1 生命（三颗血）与失败

- 进关时生命 = **3**（展示为三颗血 / 心）。  
- 每次「错误」（定义同 4.3）→ `生命 - 1`，同步熄灭一颗血的 UI。  
- **生命归零**：立刻结束本局，进入 **失败界面**（不写入星级、不推进关卡进度）。  
- 因此通关时错误次数至多为 **2**（第 3 次错误触发失败，无法再通关）。  
- 失败界面首版建议：重试本关 / 返回选关（或主界面）；重试等价于 5.4 重开。  
- 提示揭示正解 **不扣血**。



### 5.2 星级（香蕉）——错误次数 + 是否用提示

仅在 **通关成功** 时结算，三档（失败不结算星）：


| 星级  | 条件（须同时满足）                               |
| --- | --------------------------------------- |
| ★★★ | 本关错误次数 = 0，且未使用提示                       |
| ★★☆ | 本关错误次数为 1～2，且未使用提示；**或** 错误次数 = 0 但使用过提示 |
| ★☆☆ | 通关但未达到上两档（使用过提示且错误次数 ≥ 1）              |


精简判定伪代码：

```
if fail (lives == 0): 不结算星
if clear:
  if errors == 0 and hintUsed == false → 3
  else if errors <= 2 and hintUsed == false → 2
  else if errors == 0 and hintUsed == true → 2
  else → 1   // 典型：用过提示且 errors 为 1 或 2
```

- 同一关重复挑战：保留 **历史最高星**。  
- 「错误」定义见 4.3（错误双击计次；与扣血同源）。  
- 「使用过提示」：本关内成功消耗 ≥ 1 次提示即为 true。



### 5.3 提示

- **次数**：本关进入时赋予初始次数（建议默认 5，可随关卡配置覆盖）；角标显示剩余。  
- **效果（二选一，按优先级自动执行）**：  
  1. 若存在「尚未确认的正确解方块」：随机（或按教学顺序）将其中一格直接标为猴，并对其它因规则必然排除的格子 **不自动打 X**（首版只揭示一格正解，降低实现复杂度）。
  2. 若因异常无正解可揭示：对一格「必非解且仍为未定义」的格子打 X。
- 消耗：成功执行上述效果后 `剩余提示 - 1`，并标记 `hintUsed = true`。  
- 剩余为 0 时按钮禁用。  
- 提示揭示的猴计入进度，**不计错误**。



### 5.4 重开本关

- 清空所有玩家标记，错误次数与 hintUsed 归零，**生命恢复为 3**，提示次数恢复为进关初始值。  
- 不改变关卡配置与唯一解。

## 6. 关卡进度与难度曲线（轻量）



### 6.1 边长阶梯


| 阶段  | 边长 N | 用途              |
| --- | ---- | --------------- |
| 教学  | 4    | 必定位、规则演示        |
| 早期  | 5    | 巩固              |
| 主循环 | 6–7  | 日常体感（对齐参考图 6×6） |
| 进阶  | 8+   | 高难度             |




### 6.2 难度维度

- 色块形状：规整矩形 → 锯齿 / 细长条（增加「区域推理」难度）。  
- 开局可推步数：教学关保证存在「唯一可定位」格；后期减少送分步。  
- 前几关强制展示规则条，并可在第一次放猴成功后轻提示「斜角也不能碰」。



### 6.3 存档字段（只定义数据，不规定实现）


| 字段                    | 含义                       |
| --------------------- | ------------------------ |
| `currentLevelId`      | 当前可挑战 / 下一关              |
| `levelStars[levelId]` | 历史最高星 0–3                |
| `hintInventory`       | 若提示为全局库存则用此字段；若每关固定次数可不用 |
| `settings`            | 音效、音乐等                   |


通关：写入本关星级（取 max），推进 `currentLevelId`（若刚通的是最新关）。

## 7. 验收清单



### 7.1 规则判定

- [ ] N 色、每色恰 1 猴；多猴同色判非法（配置侧与运行侧）  
- [ ] 同行或同列两猴判非法  
- [ ] **斜角相邻两猴判非法**（与 ReadMe 四邻的关键差异）  
- [ ] 正交相邻两猴判非法  
- [ ] `max(|Δr|,|Δc|) ≥ 2` 的两猴可通过邻接检测  
- [ ] 找齐 N 猴触发通关  



### 7.2 操作手势

- [ ] 单击：未定义 ↔ X  
- [ ] 双击正解 → 猴；双击错解 → X + 错误 +1 + 扣 1 血  
- [ ] 滑动批量 X，不擦除已确认的猴  
- [ ] 可撤回猴与 X  



### 7.3 生命、星级与提示

- [ ] 进关 3 颗血；错误一次扣一颗  
- [ ] 第 3 次错误（生命归零）→ 失败界面，不结算星  
- [ ] 0 错且未用提示 → 三星  
- [ ] 用提示或少量错误（≤2）→ 按 5.2 降为二星或一星  
- [ ] 提示消耗次数并揭示一格正解；提示不扣血  
- [ ] 重开 / 失败后重试：重置错误、生命、提示使用标记、棋盘标记  



### 7.4 文档一致性

- [ ] 局内规则文案写「不能接触」，程序按 **八邻** 实现  
- [ ] 本文件第 0 节偏差说明对程序 / 关卡可见
