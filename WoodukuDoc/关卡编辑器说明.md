# Wooduku 关卡编辑器说明

## 打开方式

Unity 菜单：**自定义窗口 → Wooduku 关卡编辑器**

代码目录：`WoodukuClient/Assets/Editor/WoodukuLevelEditor/`

## 功能

1. **边长 N**：输入 N，棋盘为 N×N。
2. **颜色存档**：`WoodukuColorPalette` ScriptableObject（默认 `Assets/GameRes/WoodukuLevels/WoodukuColorPalette.asset`）。
   - 每种颜色可改名、改色、勾选「开」。
   - 关闭的颜色不能涂色，也不参与导出。
   - **已开启颜色数必须等于 N**。
3. **识图导入**：从玩法截图（如 `WoodukuDoc/UIGame.jpg`）识别色区，写入当前棋盘。
   - 先设好 N（与截图一致），准备好 N 个开启色板。
   - 「自动框选棋盘」或手动调裁剪边距；预览红框应为纯棋盘区域。
   - 「识别并写入当前配置」：采样每格颜色 → 聚成 N 类 → **映射到现有色板最近色**（不要求完全同色）。
   - 快捷按钮「识别 UIGame.jpg」会把 N 设为 6 并自动识别。
4. **格子标定**：选中画笔后在棋盘左键涂色 / 拖拽连涂；右键清除。
5. **检测固有解**：校验四连通色块 + 搜索解；**恰好 1 组解**视为固有解。
   - 规则：每色一猴、每行每列一猴、八邻不接触。
6. **导出 JSON**：默认 `Assets/GameRes/WoodukuLevels/level_XXX.json`。

## JSON 字段

| 字段 | 含义 |
|------|------|
| `id` | 关卡 ID |
| `size` | 边长 N |
| `hintCount` | 本关提示次数 |
| `hasUniqueSolution` | 是否固有解 |
| `solutionCount` | 检测到的解数量（最多记到 2） |
| `colors` | 逻辑色 0..N-1 的 name/hex |
| `regions` | 长度 N×N，row-major，值为逻辑色 id |
| `solutionCols` | 长度 N，`solutionCols[r]` = 第 r 行猴所在列 |
| `solutionCells` | `[{r,c}, ...]` 与上等价 |

坐标：行/列均为 `0..N-1`。
