# Monkeydoku 美术风格

## 核心定位

- 品牌名固定为 `Monkeydoku`，不得写成 Monkeydooku、Monkeydoku! 或其他拼法。
- 类型：轻松、明亮、治愈的休闲数独手游。
- 世界观：聪明的小猴子在热带森林、树屋和丛林遗迹中破解木质机关。
- 视觉品质：高张力复古热血漫画风。使用粗重墨线、密集排线、雕刻般明暗和印刷颗粒，不使用圆润 3D 卡通渲染。
- 只描述可观察的视觉特征，不要求模仿具体艺术家，也不复制现有动漫角色、服装或标志性造型。

## UI 原画出图分辨率

这个工程内所有的UI原画以竖版720*1280的设计分辨率出图.

- 整屏 UI 原画、界面 mockup、登录/主菜单/玩法背景一律竖版 `720×1280`。
- 禁止方图、横版或其它画布尺寸顶替整屏 UI 原画。
- 从整屏切出的按钮、图标、部件按 layout 像素出图，不各自改成 720×1280。
- 非整屏的角色单图仍可用 `1:1`。

## 统一视觉语言

### 色彩

- 主色：金黄、深墨绿、蓝绿色、木棕。
- 辅色：紫红、暖橙、象牙白、珊瑚红。
- 使用高饱和冷暖对比：金黄逆光对深青绿阴影，紫色仅作局部强调。
- 背景降低对比度，棋盘、数字和可交互元素保持高对比度。
- 光照使用戏剧化侧光或逆光、放射状光芒和大块明暗分区。

### 线条与质感

- 外轮廓使用粗硬黑色墨线，内部结构使用细密交叉排线。
- 阴影呈雕刻或铜版画质感，亮部可保留纸张底色和颗粒。
- 允许夸张透视、倾斜构图和富有张力的曲线，但 UI 背景中央不得被速度线或高对比细节污染。
- 禁止光滑塑料感、纯 3D 渲染、低幼扁平插画和写实摄影。

### 猴子角色

- 棕色毛发、浅色脸部、大眼睛、圆耳朵和上翘发束。
- 性格聪明、自信、活泼。可以坏笑、挑眉或摆出戏剧化英雄姿势，但不能邪恶、恐怖或凶残。
- 常用动作：手持木质数独板、举起拼块、托腮坏笑、指向目标、探头观察、完成关卡后庆祝。
- 猴子不能遮挡棋盘数字、按钮或关键信息。

### 角色单图

- 默认输出 `1:1` 半身像，主体完整，头顶、耳朵和手部不裁切。
- 使用低机位、轻微广角或斜向姿势增强张力。
- 背景使用简化热带叶片、藤蔓和放射状金光，不与角色争夺视觉焦点。
- 用户要求“坏笑”时：一侧嘴角上扬、眉毛微压、眼神自信狡黠，表现恶作剧感而非反派感。

### 材质与装饰

- 主材质使用圆角木板、竹木、浅色石板、藤蔓和叶片。
- 装饰可使用香蕉、花朵、木屑、萤火光点和树屋。
- 装饰集中在边缘，中央交互区保持干净。
- 木材、叶片和石材均使用墨线、排线和有限色块表现。
- 禁止金属科幻、霓虹赛博、暗黑恐怖、光滑 3D 塑料感和写实摄影质感。

## 棋盘规范

- 必须是完整、正视角、清晰可辨的 `9×9` 数独棋盘。
- 九个 `3×3` 宫必须通过较粗边界明确区分。
- 单格线较细，格子尺寸统一，不得出现缺格、歪斜或伪数独布局。
- 固定数字：深棕色。
- 玩家数字：森林绿或暖橙色。
- 当前选中格：香蕉黄。
- 同行、同列、同宫关联格：淡绿色。
- 冲突数字或错误格：柔和珊瑚红。
- 数字采用圆润、清晰、粗细适中的字体，优先保证可读性。

### 推荐棋盘方案

1. 藤蔓木质棋盘：暖色浅木格、深木外框，适合主玩法。
2. 丛林遗迹棋盘：浅米色石板配木框，适合章节或主题关卡。
3. 清新竹木棋盘：象牙白底、薄荷绿宫格，适合高可读性界面。

默认优先使用“藤蔓木质棋盘”。

## 界面构图

### 登录与主菜单

- 输出默认尺寸为竖版 `720×1280`。
- 标题和猴子完整放在中央约 `560×1000` 的竖向安全区内。
- `Monkeydoku` 标题宽度约 `400px`，顶部居中且不触碰安全区边缘。
- 猴子使用半身像，位于标题下方。
- 底部为关卡信息和主按钮预留空间。
- 左右边缘可使用高密度排线森林装饰，中央区域保持低对比、低细节。

### 玩法界面

- 输出默认尺寸为竖版 `720×1280`。
- 棋盘是第一视觉主体，占据画面主要面积。
- 顶部只保留关卡、分数、生命或货币等必要状态。
- 底部数字键 `1–9` 必须尺寸一致、间距清楚。
- 撤销、笔记、提示按钮使用木片或叶片图标。
- 猴子作为小助手放在棋盘顶部或侧边，不抢占操作区域。

## 特效规范

- 正确填写：短促金色冲击线、叶片微粒和高对比闪光。
- 完成一行或一宫：香蕉黄光带、翠绿叶片、少量木屑和星光。
- 连击：香蕉徽章逐级点亮，避免大面积粒子遮挡棋盘。
- 胜利：三颗金星、花瓣、香蕉亮片和猴子庆祝动作。
- 特效必须短、亮、集中，结束后立即恢复棋盘可读性。

## 图片生成流程

1. 确认用途：登录背景、主菜单、角色单图、棋盘方案、玩法截图或特效图。
2. 先锁定构图、主体位置、品牌拼写、棋盘结构和 UI 安全区。
3. 再锁定粗墨线、交叉排线、金黄逆光、深青绿阴影和印刷颗粒。
4. 明确不要模仿具体艺术家，不要现有动漫角色、乱码、水印、多余文字、棋盘畸变和主体遮挡。
5. 生成后检查：
   - 整屏 UI 原画是否为竖版 `720×1280`。
   - `Monkeydoku` 拼写是否正确。
   - 标题是否约 400px 宽并位于安全区。
   - 棋盘是否为完整 9×9，3×3 宫是否清楚。
   - 猴子是否遮挡数字或按钮。
   - 背景对比度是否低于交互区域。
   - 是否误生成圆润 3D 卡通效果。
   - 猴子的表情、手指和耳朵是否自然。

## Unity 落地

- 登录背景优先存放在 `Assets/GameRes/Textures/UI/Login/`。
- 主菜单背景优先存放在 `Assets/GameRes/Textures/UI/MainMenu/`。
- UI 图片导入为单张 Sprite，关闭 Mipmap；整屏原画最大尺寸默认 2048，避免压掉 720×1280。
- 背景 Image 关闭 Raycast Target。
- 替换背景后同时检查 `LoginBg` 与 `UI Main Menu/gameBg` 的显示效果。
